menu_bookDICIONÁRIO DE DADOS — Estrutura de Dados

Este dashboard consome dois tipos de arquivo publicados no repositório de dados abertos: uma base principal de indicações (VW_SG_V2_EP_INDIC_RECURSOS) e um conjunto de arquivos de execução financeira, um por ano (execucaoAAAA.csv — ex.: execucao2023.csv, execucao2024.csv, execucao2025.csv, execucao2026.csv), cruzados pelo Código SIAFI (campo numero_siafi, presente em ambas as fontes). Em todas as abas são exibidas apenas as indicações com Status = APROVADO. A aba Visão Geral é um agregado (soma) da base de indicações por Autoria, Ano e Tipo de Emenda. A aba Consulta por Emendas traz um registro por emenda, com dados vindos da base de indicações; os dados de execução financeira (empenhos) aparecem apenas dentro do modal de detalhes de cada emenda, na seção "Execução Financeira — Empenhos".

Indicaçõesvalor_empenhado / valor_liquidado / valor_pago / valor_empenhado_armazem / valor_liquidado_armazem / valor_pago_armazemValores brutos e valores de controle vindos do armazém de dados. Só são considerados quando existe, de fato, empenho registrado para a emenda na execução financeira (ver seção abaixo); nesse caso, Valor Empenhado, Valor Liquidado e Valor Pago exibidos na Visão Geral e na Consulta por Emendas são "atualizados" cruzando cada valor bruto com o respectivo valor do armazém, em cascata e respeitando um teto (Empenhado ≤ Valor Utilizado; Liquidado ≤ Empenhado atualizado; Pago ≤ Liquidado atualizado): se o valor do armazém for nulo/≤0, usa-se o valor bruto; se ultrapassar o teto, usa-se o teto; se for maior que o bruto (e dentro do teto), usa-se o valor do armazém; caso contrário, usa-se o bruto. A Situação é calculada a partir desses valores atualizados.

Define duas regras da Consulta por Emendas: (1) se NÃO houver nenhum empenho encontrado para o Código SIAFI da emenda, Valor Empenhado/Liquidado/Pago exibem 0,00 e a Situação fica "A EMPENHAR", mesmo que o arquivo de indicações já traga valores preenchidos; (2) se houver empenho(s) mas a soma do valor empenhado deles for zero, o(s) empenho(s) foi(ram) anulado(s) — as três colunas exibem 0,00 e a Situação fica "EMPENHO ANULADO".
